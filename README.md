# موقع فوج مليتة جربة للكشافة التونسية

موقع ثابت (HTML/CSS/JavaScript) جاهز للنشر على GitHub Pages، من غير قاعدة بيانات أو تثبيت برامج.

## الملفات
- `index.html`: محتوى الموقع.
- `style.css`: التصميم المتجاوب للهاتف والكمبيوتر.
- `script.js`: التبديل بين العربية والفرنسية، قائمة الهاتف، ونموذج التواصل.

## قبل النشر
1. افتح `script.js` وبدّل `CHANGE-ME@example.com` بالبريد الإلكتروني الرسمي للفوج.
2. بدّل الأخبار والصور التجريبية في `index.html` و`style.css` بصور ومعلومات الفوج الحقيقية.
3. زيد روابط صفحات التواصل الاجتماعي الرسمية.
4. تأكد من وجود الموافقات اللازمة قبل نشر صور الأطفال أو المشاركين.

## النشر عبر GitHub Pages
1. ادخل إلى https://github.com وسجّل الدخول.
2. اضغط `New repository`.
3. سمّي المستودع `fouj-mellita-djerba` واختر `Public` ثم `Create repository`.
4. داخل المستودع اضغط `Add file` ثم `Upload files`.
5. ارفع الملفات الثلاثة: `index.html`, `style.css`, `script.js` (تنجم زادة ترفع `README.md`).
6. اضغط `Commit changes`.
7. افتح `Settings` ثم `Pages`.
8. في `Build and deployment` اختار `Deploy from a branch`.
9. اختار الفرع `main` والمجلد `/(root)` ثم `Save`.
10. استنى شوية وعاود افتح صفحة `Settings → Pages`. الرابط يظهر عادة بالشكل:
   `https://USERNAME.github.io/fouj-mellita-djerba/`
   عوّض `USERNAME` باسم حسابك على GitHub.

## كيفاش تحدّث الموقع؟
كل مرة تبدّل ملف من GitHub وتعمل `Commit changes`، GitHub Pages يعاود ينشر التحديث آليًا بعد وقت قصير.

## ملاحظات مهمّة
- نموذج التواصل يفتح تطبيق البريد الإلكتروني، وما يخزّنش الرسائل في الموقع.
- الصور المستعملة أمثلة من Unsplash؛ استبدلها بصور عندك الحق في استعمالها.
- الموقع ثنائي اللغة: زر `FR` / `عربي` يبدّل اللغة واتجاه الصفحة.
